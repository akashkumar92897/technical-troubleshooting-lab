# Windows Slow Performance

## Scenario

A user reports that their Windows computer has become unusually slow.

The user says that applications take longer than usual to open, the system becomes unresponsive at times, and switching between applications is slower than normal.

The objective is to identify the likely cause systematically rather than applying random fixes.

---

## Symptoms

Reported symptoms may include:

- Applications take a long time to open.
- The system becomes temporarily unresponsive.
- Switching between applications is slow.
- The computer takes longer than usual to start.
- Files or folders take longer to open.
- The system may become slow when multiple applications are running.

---

## Information to Collect

Before troubleshooting, gather relevant information from the user.

### Basic Questions

- When did the problem start?
- Was the computer previously working normally?
- Does the slowdown happen continuously or only during certain tasks?
- Did the user install or update any software recently?
- Does the problem occur after starting Windows or only after using the system for some time?
- Are specific applications affected or is the entire system slow?
- Does restarting the computer temporarily improve performance?
- How much free storage is available?

### Scope

Determine whether the issue affects:

- The entire computer
- A specific application
- A specific user
- A particular task

Understanding the scope helps narrow down the possible causes.

---

## Possible Causes

Common causes of Windows performance problems can include:

- High CPU utilization
- High memory utilization
- High disk utilization
- Too many background processes
- Too many startup applications
- Insufficient free storage
- Resource-intensive applications
- Recent software or system changes
- Outdated or problematic drivers
- Pending system updates
- Hardware limitations or hardware problems

These are possible causes, not assumptions. They should be investigated before determining the root cause.

---

## Troubleshooting Steps

### Step 1 — Check Resource Utilization

Open **Task Manager** and review:

- CPU usage
- Memory usage
- Disk usage
- Network usage
- Running processes

Identify whether any process is consuming an unusually large amount of system resources.
